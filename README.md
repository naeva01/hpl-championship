# Hostel Premier League (HPL)

Hostel Premier League (HPL) is a simple Python-based system for managing a hostel sports league. It allows users to create hostel teams, add players, record match results, maintain a points table, and declare the championship winner.

## Features

* Add hostel teams
* Add players to teams
* Store up to 11 players in each team
* Record match results
* Automatically update wins and points
* Display the HPL points table
* Display all registered players
* Declare the champion and runner-up
* Save team and match data in text files
* Save the final winner information

## Installation

1. Install Python 3 on your computer.
2. Download or clone this project.
3. Save the Python file in a folder.
4. Open the folder in a terminal or command prompt.
5. Run the program using:

```bash
python hpl.py
```
