# Problem Statement

Managing a hostel sports league manually can become difficult when there are multiple teams and players. Keeping track of team members, match results, wins, points, and the final winner using notebooks or separate records can take time and may lead to mistakes.

The Hostel Premier League needs a simple system that can keep all this information organized and make basic league management easier.

# Solution

The Hostel Premier League (HPL) system is developed using Python to manage the basic activities of a hostel sports league.

The program allows the user to add hostel teams and register players under each team. It also allows match results to be recorded. When a team wins a match, its wins and points are automatically updated.

The system can display the current points table, show all registered players, and declare the champion based on the points earned by the teams. The team and match information is also stored in text files so that the data can be used again when the program is run.

Overall, the project provides a simple and organized way to manage the teams, players, matches, points, and winner of the Hostel Premier League.
